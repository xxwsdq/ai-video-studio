AI VIDEO STUDIO v0.1 — стартовый прототип

УЖЕ РАБОТАЕТ:
- мобильный интерфейс;
- создание проектов из описания;
- автоматический план из 7 этапов;
- разделы проектов, команды ИИ, очереди, настроек;
- сохранение проектов в браузере (localStorage);
- экспорт резервной копии JSON;
- архитектурное правило: один активный исполнитель за раз;
- закреплён контроль единого визуального стиля.

ПОКА НЕ РАБОТАЕТ:
- реальные API-вызовы ChatGPT, Claude, DeepSeek и ElevenLabs;
- генерация картинок, озвучки и MP4;
- облачный фоновый диспетчер.
Статус «ожидает подключения» честно означает, что внешняя интеграция ещё не сделана.

КАК ОТКРЫТЬ:
1. Распакуй архив.
2. Для теста открой index.html браузером (если Android предлагает этот вариант).
3. Для стабильной работы размести содержимое папки на GitHub Pages.
4. Открой опубликованный адрес в Chrome и выбери «Добавить на главный экран».

АРХИТЕКТУРА СЛЕДУЮЩИХ ЭТАПОВ:
- Sequential Orchestrator: выбирает исполнителя и запускает одну задачу за раз.
- Provider adapters: API-адаптеры каждого сервиса.
- Job queue: попытки, ошибки, лимиты, ожидание и возобновление.
- Style Bible + эталонные кадры + листы персонажей.
- Quality Gate: отклонение кадров, выбивающихся из стиля.
- Video Engine: кадры, движение камеры, звук, субтитры, экспорт MP4.

ВАЖНО:
API-ключи нельзя хранить в публичном JavaScript или GitHub Pages.
Нужен защищённый серверный посредник или безопасное хранилище секретов.
Само приложение не может обходить лимиты API.
